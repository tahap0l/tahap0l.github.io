# tahap0l.github.io

Personal portfolio of **Esat Taha Polat** → **https://tahap0l.github.io**

- Bilingual (TR / EN), framework-free HTML, CSS and JavaScript
- Interactive StreamDeckk demo: the sound effects are synthesized in the browser with the same formulas as `StreamDeckk.Core/Samples.cs`
- Live data from the GitHub API (latest release, language breakdown, recent commits) with offline fallbacks
- Respects `prefers-reduced-motion`, responsive on phones and desktops

Hosted on GitHub Pages from the `main` branch.
